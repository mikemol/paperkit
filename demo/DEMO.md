# paperkit consumes its own consumer_fields

*The one project that DECLARES a consumer field and carries it on a claim — so the feature paperkit documents and proves is also DEMONSTRATED end-to-end, and the parse paths that must stay quiet on a declared field have a live exercise (a declared field warns ZERO times; a project with none cannot exhibit that).*

## The Demonstration

Paperkit demonstrates the consumer_fields capability on its own tree — this claim carries a `provenance` field, declared by this project's paper.toml, that no paperkit invariant reads but the engine parses and carries verbatim, so the feature documented in prose and proven in the boundary suite is also EXERCISED by a real gated project (without which a declared field's carry-and-stay-quiet path is invisible from inside paperkit — a vacuous pass on a tree that declares none) [@demo-carries-a-declared-field].
